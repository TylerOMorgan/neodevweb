# NeoDev Studio — Next.js Revamp

Premium Next.js App Router website for NeoDev Studio.

## Hero preview
The hero automatically rotates between four system views:
- n8n workflow
- CRM dashboard
- VPS scraper
- AI agent

The n8n state uses the user-provided n8n workflow reference image at `public/n8n-workflow-reference.png` and keeps the surrounding UI responsive.

```

```

The full experience uses purple as the dominant brand accent: navigation, CTAs, typography highlights, cards, marquee, process section, hero glow, contact section, and interactive states.
